# 한자 공부 노트

한국 한자 음훈은 libhangul의 한자 사전 자료(Choe Hwanjin, BSD 3-Clause)를 바탕으로 하며, 일본 신자체의 대응 자형과 보조 한국 한자음에는 Unicode Unihan 자료를 사용합니다. 각각의 이용 조건은 `LICENSE-HANJA.txt`와 `LICENSE-UNICODE.txt`를 확인하세요. 일본에서 만든 한자 등 일부 글자는 한국 한자 음훈이 없거나 확인되지 않아 그렇게 표시합니다. 음독·훈독의 개별 어원은 확인된 경우에만 설명합니다.

단어 아래의 예문은 이 앱에 수록된 이야기에서 찾은 문장과 직접 작성한 문장입니다. 아직 예문을 확인하지 못한 단어에는 ‘예문 준비 중’이라고 표시합니다. 동사 등은 문장 안에서 활용된 형태로 나올 수 있습니다.

## 새 연재 이야기와 한자 기억 이야기

`04 이야기`에는 다섯 세트를 한 묶음으로 읽는 학원 미스터리 연재 9편(각 5장, 총 45장)이 추가되었습니다. 각 연재는 일본어 약 1,800~2,100자이며 장별 한국어 번역을 제공합니다. 검색창에 `1`, `2`, `3`, `4`, `5` 중 어느 번호를 입력해도 1~5세트 연재의 다섯 장이 나타납니다. `6`~`10`은 다음 연재이며 같은 방식으로 45세트까지 찾을 수 있습니다. 장 아래의 버튼으로 이동하고 `이 장 읽음`으로 읽기 진행을 표시할 수 있습니다. 기존 짧은 이야기 90편도 계속 볼 수 있습니다.

새 연재의 일본어 본문에 쓰인 모든 한자는 문맥별 후리가나가 붙습니다. 기본 읽기는 Kuromoji/IPADIC 분석 결과이며 시간 표현 몇 개는 직접 교정했습니다. 고유명사나 드문 표현의 자동 읽기에는 오차가 있을 수 있습니다. 단어를 누르면 기존 뜻풀이와 카드 상태 버튼도 사용할 수 있습니다. 음성 재생은 브라우저의 일본어 음성에 의존합니다.

`01 한자 살펴보기`의 오른쪽 `글자 이야기`는 한자를 바꾸거나 다시 선택하면 접힌 상태로 시작하며 눌러서 펼칠 수 있습니다. 구성 요소는 독립적인 뜻을 설명하며, 1세트와 5세트의 각 한자에는 직접 쓴 기억 이야기가 있습니다. 다른 글자에도 알려진 부품의 뜻과 단어를 연결하는 힌트를 제공합니다. 巡·企·伸·抱·涙·扱의 유래는 [漢字ペディア](https://www.kanjipedia.jp/)를 확인하여 출처를 붙였습니다. 나머지의 역사적 역할은 검증 중이라고 표시합니다. 부품 자체의 뜻, 기억용 상상, 실제 유래는 서로 다를 수 있습니다. `나만의 기억 이야기`는 현재 브라우저에 저장됩니다.

`02 단어 카드`, `03 쓰기 연습`, `04 이야기`에서 각각 세트 선택을 펼쳐 하나 또는 여러 세트를 고를 수 있습니다. 이야기는 선택한 세트 중 하나에 해당하는 작품을 보여 주며 검색어도 함께 적용합니다. 이야기 속 45세트의 학습 한자는 다른 세트의 글자라도 강조되며, 단어를 누르면 세트 번호와 해당 한자로 이동하는 버튼을 볼 수 있습니다. 새 연재와 기존 이야기 모두에 문맥별 후리가나가 제공됩니다. 자동 분석한 읽기는 이름이나 문맥에서 틀릴 수 있습니다.

같은 폴더에 있는 `0.open this.html`을 최신 브라우저에서 열면 됩니다. HTML, CSS, JavaScript 파일을 함께 보관해 주세요. 앱 자체는 설치나 계정이 필요하지 않습니다.

한자 살펴보기에서 한자를 ‘모름’, ‘익힘’, ‘복습 필요’으로 정할 수 있습니다. 여기에서 고른 상태는 해당 한자의 두 단어 카드에 적용됩니다. 카드 화면에서는 각 단어의 상태를 따로 옮길 수 있습니다. 세트와 상태, 순서와 연습할 한자 수를 고르세요. 한자 하나에 단어 카드가 두 장이며, 상태별로 걸렀을 때는 해당 상태인 카드만 나타납니다. ‘세트 단어 전체’는 담지 않은 단어도 표시합니다. ‘다음 묶음’은 선택한 순서에 따라 다음 한자로 넘어갑니다. ‘다시 뽑기’는 단어 카드들을 새로 섞고 가능한 한 같은 한자의 단어가 연속되지 않게 합니다. 카드 관리에서는 상태별 필터와 색상으로 한자를 볼 수 있습니다. 두 단어의 상태가 다르면 각각 표시하며, 살펴보기에서는 연습할 상태를 먼저 표시합니다.

한자 살펴보기에서 세트 완료를 직접 체크할 수 있습니다. 이 표시는 개별 단어 카드 상태를 자동으로 바꾸지 않습니다. 이야기에 표시된 단어는 마우스를 올리거나 터치하면 일본어 읽기와 한국어 뜻을 볼 수 있고, 안에 있는 학습 한자를 카드에 담을 수 있습니다. 후리가나와 한국어 전체 번역은 각각 버튼으로 켜고 끌 수 있습니다. 이야기 검색창에 `3`처럼 숫자를 입력하면 해당 세트의 이야기를 찾습니다.

이야기 음성은 기기와 브라우저의 일본어 음성을 이용합니다. 음성 재생 위치는 초 단위가 아니라 **문장 단위**입니다. 일본어 음성의 설치 여부에 따라 발음과 사용 가능 여부가 달라집니다. 한국어 발음 표기는 일본어 소리의 근사치입니다.

쓰기 화면에서 세트를 선택할 수 있습니다. 안내를 끄면 글자와 검색·선택 영역은 숨기고, 두 예시 단어에서는 연습할 한자만 □로 표시합니다. 표시된 후리가나는 글자 하나가 아니라 단어 전체의 읽기입니다. 쓰기 설명은 부품에 관한 참고 사항이며 번호가 붙은 획순 그림은 아닙니다.

카드와 세트 완료 상태는 해당 기기의 해당 브라우저에만 저장되며 기기 사이에 자동 동기화되지 않습니다. 브라우저 데이터를 지우면 저장 내용도 사라질 수 있습니다. 카드 화면에서 상태를 파일로 내보내어 다른 기기로 옮긴 뒤 가져올 수 있습니다. 같은 카드의 상태가 이미 있으면 가져온 값으로 바뀝니다. 인터넷이 없어도 앱의 기능을 쓸 수 있지만 온라인 글꼴을 불러오지 못하면 기본 글꼴로 표시됩니다.

공부할 수 있는 한자와 이야기 수는 앱의 첫 화면에서 확인할 수 있습니다. 목록에 없는 한자와 이야기는 아직 작성되지 않은 것입니다.
